### 数据成员

| 类型                            | 成员          | 初值 / 范围   | 含义与所有权                 |
| ----------------------------- | ----------- | --------- | ---------------------- |
| ComPtr\<ID3D12DescriptorHeap> | mHeap       | nullptr   | 保存描述符堆的接口指针；拥有         |
| UINT                          | mSingleSize | 0         | 单个Descriptor的地址增量；值    |
| UINT                          | mCapacity   | 0         | 类中有多少个DescriptorHeap；值 |
| D3D12_DESCRIPTOR_HEAP_TYPE    | mType       | TYPE最大枚举值 | Descriptor Heap的类型；值   |

### 不变量

| 编号  | 条件                         | 成立边界  |
| --- | -------------------------- | ----- |
| I1  | `mHeap != nullptr`         | Ready |
| I2  | `mSingleSize > 0`          | Ready |
| I3  | `mCapcacity > 0`           | Ready |
| I4  | `0 <= index < mCapacity`   | Ready |
| I5  | `mType`与实际`mHeap`的描述符堆类型一致 | Ready |

### 接口与生命周期

| 接口                    | 行为                                                    | 前提 / 边界                                                   |
| --------------------- | ----------------------------------------------------- | --------------------------------------------------------- |
| CpuHandle(UINT index) | 返回index对应下标的描述符堆的CPU句柄                                | I1, I4                                                    |
| Type                  | 返回mType                                               |                                                           |
| Capacity              | 返回Capacity                                            |                                                           |
| Get                   | 返回mHeap const观察指针                                     |                                                           |

| 函数签名 | 可见性    | 行为                                                         | 前提/边界                    |
| ---- | ------ | ---------------------------------------------------------- | ------------------------ |
| 构造函数 | public | RAII，根据传入`capacity`，初始化对应容量的描述符堆与成员变量，`this`对象的状态进入`Ready` | 传入描述符堆类型需要为`RTV` 或 `DSV` |
- 持有与销毁：Dx12Renderer实例；释放：在释放Wnd窗口前释放该实例。
